# 📊 HR Analytics Dashboard

An interactive dashboard built to analyze **employee attrition** and uncover key insights to support better HR decision-making.

## 📌 Overview

Employee attrition impacts productivity and business growth.  
This project focuses on identifying patterns and factors that influence employee turnover using data analysis and visualization.

## 🎯 Objective

- Analyze employee attrition trends  
- Identify high-risk employee groups  
- Provide insights for improving retention strategies  

## 📊 Key Metrics

- 👥 Total Employees: **446**  
- 📉 Attrition Count: **92**  
- 📊 Attrition Rate: **20.6%**  
- 🎂 Average Age: **37 years**  
- 💰 Avg Monthly Income: **7K**  
- ⏳ Avg Working Years: **7.3 years**  

## 📈 Key Insights

- Highest attrition observed in **26–35 age group**  
- Employees with **salary ≤10K** are more likely to leave  
- **Sales Executives** have the highest attrition  
- Most employees leave within **first 3 years**  
- Higher attrition seen in **Marketing & Life Sciences** backgrounds  

## 📊 Dashboard Features

- Attrition by Age Group  
- Attrition by Salary  
- Attrition by Job Role  
- Attrition by Education  
- Attrition by Years at Company  
- Gender-wise Attrition Analysis
  
## 🛠️ Tools & Technologies
